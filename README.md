# 🦙 Веб-приложение «Ставропольский Зоопарк — Страничка Альпаки»

Веб-приложение на платформе **ASP.NET Core 8 MVC** с архитектурой поддоменного роутинга (`/stav-zoo`, `/stav-zoo/alpaca`), интерактивным личным кабинетом, системой аутентификации и авторизации (Cookie + JWT), REST API с поддержкой Swagger, базой данных SQLite (Entity Framework Core) и полнофункциональным дневником наблюдений для работников зоопарка.

---

## 🌟 Основные возможности

### 1. 🌿 Публичная страничка для всех пользователей и гостей
- **История и биография питомцев**: Подробный паспорт особи, происхождение вида, хронология появления в зоопарке, характер и повадки альпак Пако и Лолы.
- **Медиагалерея и видео**: Качественная галерея фотографий с просмотром в полноэкранном режиме (Lightbox), видеоматериалы из жизни вольера.
- **Онлайн-наблюдение (Веб-камера 24/7)**: Интерактивный плеер трансляции с реальным таймкодом, индикатором LIVE HD и переключением ракурсов (общий вид вольера, зона кормления, теневой домик).
- **Благотворительные пожертвования (Free Donation)**:
  - Форма выбора суммы через быстрые пресеты (200, 500, 1000, 2500, 5000 ₽) или ввод произвольной суммы.
  - Выбор целевого назначения (лакомства, витамины, теплый домик, свободный донат).
  - Прогресс-бар сбора средств на текущий месяц в реальном времени.
  - Лента последних донаторов с мгновенным динамическим обновлением без перезагрузки страницы.

### 2. 📖 Дневник наблюдений особи (для работников зоопарка)
- Доступен для чтения всем посетителям.
- **Авторизованные сотрудники (Зоотехники, Ветеринары, Администрация)** имеют полные права на ведение дневника:
  - **Кормёжка**: фиксация рациона, добавок, аппетита.
  - **Спаривание и репродукция**: брачное поведение, даты и особенности гона.
  - **Потомство**: результаты УЗИ, гестация, развитие плода.
  - **Ветеринария**: вакцинации, прием витаминов, анализы.
  - **Уход и стрижка**: расчистка копытец, уход за шерстью.
  - **Поведение**: обогащение среды, адаптация, игры.
- **Фильтрация и поиск**: по категориям и поисковым фразам.
- **Экспорт данных**: выгрузка записей дневника в форматы **JSON** и **CSV**.

### 3. 🔐 Аутентификация и авторизация (Cookie + JWT)
- Гибридная модель авторизации: Cookie для веб-интерфейса + JWT Bearer токены для REST API.
- Предустановленные тестовые аккаунты с быстрыми кнопками входа в 1 клик на странице логина:
  - 👷 **Зоотехник**: `keeper@stavzoo.ru` / `Password123!` (Роль: `Employee`)
  - 🩺 **Главный ветврач**: `vet@stavzoo.ru` / `Password123!` (Роль: `Employee`)
  - 👤 **Посетитель / Гость**: `guest@mail.ru` / `Password123!` (Роль: `User`)

### 4. 🚀 REST API и Swagger
- Интерактивная документация Swagger доступна по адресу `/swagger`.
- Эндпоинты:
  - `GET /api/animals` — список всех животных
  - `GET /api/animals/{slug}` — подробная информация о животном (напр. `alpaca`)
  - `GET /api/animals/{slug}/diary` — получение записей дневника с фильтрацией
  - `POST /api/animals/{slug}/diary` — создание записи (требуется роль `Employee` / JWT Bearer)
  - `PUT /api/animals/{slug}/diary/{id}` — редактирование записи (требуется роль `Employee` / JWT Bearer)
  - `DELETE /api/animals/{slug}/diary/{id}` — удаление записи (требуется роль `Employee` / JWT Bearer)
  - `POST /api/donations` — отправка благотворительного пожертвования
  - `GET /api/donations/{slug}` — получение статистики донатов
  - `POST /api/auth/login` — вход и выдача JWT-токена
  - `POST /api/auth/register` — регистрация
  - `GET /api/auth/me` — профиль текущего пользователя

## 🗂️ Роутинг приложения

| URL | Описание |
|---|---|
| `/` | Автоматический редирект на `/stav-zoo` |
| `/stav-zoo` | Главная страница каталога Ставропольского зоопарка |
| `/stav-zoo/alpaca` | **Страничка Альпаки (Пако и Лола)** |
| `/stav-zoo/lynx` | Страничка Рыси Север |
| `/stav-zoo/capybara` | Страничка Капибары Борис |
| `/auth/login` | Страница входа с кнопками быстрого демо-доступа |
| `/auth/register` | Страница регистрации нового пользователя |
| `/swagger` | Интерактивная документация REST API (Swagger UI) |

## 🛠️ Запуск проекта

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Команда запуска:
```powershell
cd StavZooApp
dotnet run --urls "http://localhost:5000"
```

После запуска откройте в браузере:
- **Главная страничка альпак:** [http://localhost:5000/stav-zoo/alpaca](http://localhost:5000/stav-zoo/alpaca)
- **Портал зоопарка:** [http://localhost:5000/stav-zoo](http://localhost:5000/stav-zoo)
- **Swagger API:** [http://localhost:5000/swagger](http://localhost:5000/swagger)
